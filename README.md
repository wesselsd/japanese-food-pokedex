# Japanese Food Pokedex

A mobile-first web app for discovering Japanese food, tracking dishes eaten, and storing food photos.

## Project structure

- `pokedex/` - Nuxt website
- `thoughts/` - Design decisions, research, and project notes

## Planned stack

- Nuxt
- Vue
- Supabase
- Tailwind CSS
- GitHub Pages

## Run locally

From the repository root:

```bash
cd pokedex
npm install
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:3000`.

To generate and preview the static production build locally:

```bash
cd pokedex
npm run generate
npm run preview
```
